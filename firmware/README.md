# Precompiled UF2 Firmware

These files are compiled for the Waveshare RP2040 Zero using the Earle Philhower RP2040 Arduino core with `USB Stack` set to `Adafruit TinyUSB`.

To install one:

1. Hold `BOOTSEL` while plugging in the board.
2. Wait for the board to appear as a USB drive.
3. Copy the desired `.uf2` file onto that drive.
4. The board will reboot into the new firmware.

Available firmware:

- `Dronaldo.uf2`
- `DrumLoop.uf2`
