# Bundled Arduino Libraries

This folder contains Arduino libraries needed by the workshop examples.

Students should copy these folders into their Arduino libraries folder:

```text
libraries/BRAIDS/
libraries/STMLIB/
```

Typical Windows destination:

```text
Documents/Arduino/libraries/BRAIDS/
Documents/Arduino/libraries/STMLIB/
```

Restart Arduino IDE after copying them.

These are third-party Mutable Instruments related audio libraries. Keep their license and attribution files with the library folders.

See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for attribution notes.
