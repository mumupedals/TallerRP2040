# Third-Party Notices

This folder vendors third-party Arduino audio libraries used by the workshop sketches.

## BRAIDS

- Folder: `libraries/BRAIDS`
- Arduino include: `#include <BRAIDS.h>`
- Source noted in `library.properties`: https://github.com/poetaster/arduinoMI
- Original DSP code is associated with Mutable Instruments Braids by Emilie Gillet.
- License information appears in the source file headers. Keep those headers intact when redistributing or modifying the code.

## STMLIB

- Folder: `libraries/STMLIB`
- Arduino include: `#include <STMLIB.h>`
- Source noted in `library.properties`: https://github.com/poetaster/mozzimi
- The bundled folder includes license files at `libraries/STMLIB/LICENSE` and `libraries/STMLIB/src/stmlib/LICENSE`.

Before making a public release, review the third-party licenses and make sure the repository license you choose for the workshop materials does not conflict with these libraries.
